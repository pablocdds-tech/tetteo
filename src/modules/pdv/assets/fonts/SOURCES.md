# Muli

Família usada na interface de referência e distribuída pelo Google Fonts.
Arquivos completos TrueType, pesos 300, 400, 600 e 700, versão servida `v34`.
Hospedagem local pelo `next/font/local`; o navegador não consulta o Google.

Fonte oficial: https://fonts.googleapis.com/css2?family=Muli:wght@300;400;600;700&display=swap
